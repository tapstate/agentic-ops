# PROD-002 在副作用前执行统一门禁

Agent 在调用 Git、GitHub、Jira 等副作用操作前，Adapter 先生成标准操作请求，
统一门禁根据操作、任务授权、
仓库和分支返回 `allow`、`ask` 或 `deny`。

### 验收标准

- 常规只读不受控；有效授权只覆盖明确列出的任务操作。
- 未知外部写转人工；强推、历史改写和保护分支写入拒绝。

### 保护行为

- 过期、撤销或绑定不匹配的授权不能继续放行。
- Hook 不替代最小权限、服务端保护和外部事实回读。

### 验收证据

- 操作分类、三态判定和二态降级测试结果。
- 无效协议版本、缺失字段和未知标准操作的保守处理结果。
- 多仓绑定失效、保护分支和审计事件测试结果。
