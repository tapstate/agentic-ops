# PROD-002 在副作用前执行统一门禁

Agent 在调用 Git、GitHub、Jira 等副作用操作前，Adapter 先生成标准操作请求，统一门禁根据操作、任务授权、仓库和分支返回 `allow`、`ask` 或 `deny`。

### 验收标准

- MCP 按服务标识和工具名的完整身份映射；只有明确映射到标准操作的调用进入统一门禁，普通命令和未映射工具不生成 Gate 请求，交还 Agent 平台原生权限流程。
- 明确属于受控操作族但因包装、目标或参数歧义而无法可靠映射时转人工；强推、历史改写和保护分支写入拒绝。
- Claude 与 Codex 共用 Tool Adapter 分类语义，只允许原生 Hook 输出协议存在差异。

### 保护行为

- 过期、撤销或绑定不匹配的授权不能继续放行。
- Adapter 或 Gate 故障失败关闭；未命中操作不得被伪装成 AgenticOps `allow`。
- 任意解释器、未登记脚本和未映射工具依赖 Agent 原生沙箱与权限流程；Hook 不替代最小权限、服务端保护和外部事实回读。

### 验收证据

- MCP 完整身份、Shell 分段、动态别名、正向命中、受控操作歧义、未命中透传、三态判定和二态降级测试结果。
- 无效协议版本、缺失字段和未知标准操作的保守处理结果。
- 多仓绑定失效、保护分支、双 Agent 分类一致性和审计事件测试结果。
