# INT-001 审查并发布 AgenticOps

项目维护者在 `develop` 形成经过影响范围验收的候选，通过代码审查后发布到 `main`。内部治理工具只服务 AgenticOps 仓库，不构成第二套产品 Runtime。

### 验收标准

- 普通提交/PR 候选按确定性影响范围验收，至少运行资源边界；共享实现、契约、安装、门禁及无法可靠映射的变更回到 Runtime、Resources、Install、Release 完整四项。发布在隔离环境独立执行完整四项；同一发布的有效证据跨准备、发布与恢复复用，不把每次入口调用当作重验；故事注册表在 Runtime 内覆盖，不另作为第五项重复执行。诊断检查不生成提交放行证据。
- 验收证据 v6 绑定完整候选树、精确比较基线、变更范围、选择器内容摘要、最低检查集合、实际执行集合及可移植环境事实。staged 验收前后工作树必须与索引一致，range 必须实际检出指定 Head；漂移不能通过。
- `main`、版本 Tag 和发布写入只通过版本化发布流程完成。合并前固定发布方式、版本（如需要）、目标基线与候选；合并后核验实际双父提交和完整树，漂移不得借用旧验证结果发布。
- 信任根 Hotfix 走人工审查 PR，无版本 Tag；epoch 不决定发布方式。正常与恢复均明确区分已交付和 develop 同步待办，保留并行开发提交。

### 分阶段验收场景

- 同 epoch 可直接准备正式版本，不要求例外理由；跨 epoch Hotfix 保留人工审查要求。
- 纯本地候选明确绑定旧 SHA 后可重新准备同版本，保留旧提交和证据；缺少决定、SHA 漂移、远端分支/PR/Tag 已存在、工作树占用或验收失败时不替换。源码候选变化不沿用旧批准。

- GitHub Auto-merge 关闭、main 未配置保护、尚无推送范围批准或历史验收记录时，合法候选仍能完成本地 `prepare` 和独立完整验收，只生成本地分支/证据；不修改设置、不推送、不把准备通过标成可交付。
- prepare 后可在没有另一份开发范围验收/批准记录的情况下，凭有效发布证据及明确提交操作确认接续审查，不重复四项。缺少确认、证据失效或基线漂移时不推送。固定分支冲突在测试前报告；inspect 引导已有候选进入审查。
- 信任根候选默认 hard 提交人工审查 PR，不要求 soft 或 Auto-merge；PR 保持待审查，提交本身不触发合并和 Tag。
- 人工合并后，hard `recover` 可复用证据收尾；缺少 main 保护、未取得固定对象的用户确认或仍有未解除的要求修改时不得创建 Tag。单人维护无 GitHub APPROVED 记录不自阻塞，也不能据此推定人工已审查。更严格且名称不同的有效规则集可通过。
- 普通自动发布单独检查 Auto-merge；人工审查及恢复不受该开关限制。治理配置必须单独授权，不借 prepare、审查提交或恢复修改设置。

分阶段职责和支持边界唯一见[维护指引](../../maintenance-guide.md#6-发布与-hotfix)，此处仅定义验收场景。

### 保护行为

- `internal/` 不进入研发安装目录，也不被业务 Agent 加载。
- 候选修改门禁实现时不能用未暂存代码替代受审查内容。
- 正式重验立即撤销旧通过结果与同候选审批；稳定锁覆盖完整执行和进程回收。失败、取消、超时不会恢复旧通过。每次运行独立保留日志，消费的摘要自包含计划检查集合、实际结果、验收范围与日志摘要；局部结果不能冒充完整验收。
- v3/v4/v5 证据保留查阅，不满足 v6 选择与候选绑定合同，不双写或伪装旧格式。首次升级通过受保护 main 的人工审查 PR；旧发布门禁拒绝 v6 为预期，不增加旁路。发布仍独立执行隔离环境四项验收，不消费开发结果代替发布验证；发布专用证据的复用、失效及恢复遵循[维护指引](../../maintenance-guide.md#发布验证复用与合并后收尾)。
- Agent Hook、共享 Adapter Runtime 或 Tool Adapter 分类策略变化时，自动发布失败关闭，只能通过受保护 `main` 的人工审查 PR 升级信任根。
- 本次 v1 重构允许删除旧 `developer/`、`maintainer/` 和 `shared/` 资产；这些路径后续重新出现时仍进入内部治理并由资源合同拒绝。

### 验收证据

- 按影响范围或完整验收的计划与结果、候选提交和代码审查事实。
- 发布后 `main`、`develop` 和 Tag（正式版本）指向回读；Hotfix 不生成 Tag。验收覆盖有效证据下合并后零次完整重验、失败后旧证据失效、未知写入回读、源分支删除恢复及并行 develop 的准确待办。
