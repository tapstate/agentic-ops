# INT-001 审查并发布 AgenticOps

项目维护者在 `develop` 形成经过固定验证的候选，通过代码审查后发布到 `main`。
内部治理工具只服务 AgenticOps 仓库，不构成第二套产品 Runtime。

### 验收标准

- 产品主链路、资源合同、故事注册表和发布流程分别可执行验证。
- `main`、版本 Tag 和发布写入只通过版本化发布流程完成。

### 保护行为

- `internal/` 不进入研发安装目录，也不被业务 Agent 加载。
- 候选修改门禁实现时不能用未暂存代码替代受审查内容。
- 本次 v1 重构允许删除旧 `developer/`、`maintainer/` 和 `shared/` 资产；这些路径
  后续重新出现时仍进入内部治理并由资源合同拒绝。

### 验收证据

- 固定验证、候选提交和代码审查事实。
- 发布后 `main`、`develop` 和 Tag 指向回读。
