# PROD-003 推进并恢复多仓库研发任务

一个项目工位同一时间只接管一个 Jira 任务，每个任务可修改完整工程中的多个仓库；Agent 中断后恢复同一 run/op，汇总各仓 PR、CI 与验证证据。并发由多个独立工位承担。

### 验收标准

- 阶段不可跳跃；准入按项目规则核对，缺少授权或可靠仓库基线会阻断受影响步骤。启用质量处置模式时，普通缺项先披露，推进检查点必须有用户处置记录，不要求所有测试全绿。
- 检查点包含多个检查项，每项绑定一个用例和一种验证方式；修复前后项分阶段到期，原始执行结果、用户选择和风险处置独立保存，具体操作见[质量检查与证据](../../usage/quality-checkpoints.md)。
- current-task.json 唯一绑定当前任务；新接管生成 Jira 任务号绑定的固定 8 位秒级 HEX run-id，恢复保持同一 run；operation 未结束阻止接新任务；活动授权、质量、CI 和证据精确绑定 run。
- 同工位不可并发任务；Workflow 状态变更显式绑定 issue/run，advance 另绑定预期阶段，旧请求失败关闭；不依赖通用工具 Hook。
- 一个授权绑定多个仓库，每仓独立校验 origin、分支、范围和验证方式。
- 新修改分支由工位首次固化的全局 Git `user.name` 与当前 run 生成；身份缺失只暂停代码变更步骤并给出补配说明，续办沿用已核验的历史分支。
- 每工位使用独立 source/<owner>/<repo> 和完整冻结工程基线；任务修改仓记录引用唯一基线。
- 同 run/op 恢复幂等；归档未完成任务后停止开发且仍占用，精确 clean 成功才释放；完成任务由研发 release。
- 清理按明确成果标准验收，内置脚本和 Agent 原生工具使用同一标准；脚本异常可在原授权范围接力，不以命令退出码或指定中间步骤作为完成依据。实际残留、保全不足或事实不明不能解绑，具体合同见[成果导向清理](../../architecture/single-task-station.md#成果导向清理计划版本-6)。
- 当前 run 保存初始 Jira 快照和本地确认事实；版本不映射 Git 分支。接管水印尽力同步，外部失败或结果不明保留待办，不阻止本地推进；未知操作先回读。
- 缺陷接管成功后同步尝试一次 `In Progress`，Q4 验收完成后同步尝试一次 `Tests Passed`；已达目标直接记录，其它状态、必填字段不足或外部失败均记录并跳过，不阻断本地主流程，也不自动执行 `Pull Request Submitted`。
- PR Ready 前核对 Jira 关联测试任务全部完成、当前 PR Head 的 Checks 全部明确成功，以及 Q1-Q4 和其检查项全部通过或明确不适用；三类事实分别保留来源和具体待办。

### 保护行为

- 新增仓库或修改稳定绑定后旧授权失效。
- 其它工位源码、共享缓存、未知资源不能进入清理范围；未确认内容不删除。
- 本地任务分支与独立仓库保留；残留分支不静默复用，源码中的暂存、未暂存、未跟踪和 ignored 内容按确认快照保全或明确处置，不按构建目录名称删除。运行目录按当前任务归属回收，未知范围不删除。
- PR/CI 结果不改变授权指纹；合并和发布不被任务授权覆盖。
- Jira 状态及水印同步绑定当前 task/run 与精确目标；原生工具负责发送，Workflow 保存意图和回读，不保证工具调用次数。同步失败不能阻断无依赖的本地推进，也不能伪装成成功。
- 质量确认绑定对应计划、代码及证据；内容变化使受影响确认失效。旧 run、其它仓库的同号 PR、跳过或未知结果不能冒充当前用例通过；风险处置不能代替安全授权或 Jira Validator。
- 外部评论须先持久记录已确认草稿的写入意图；回执不明先核对，回读匹配后才能确认发送结果。记录损坏及并发旧 revision 保留现场并拒绝覆盖。
- 未知评论不阻止不同检查点回写；简洁正文、目标和评论编号仍须匹配，短标识仅供定位。PR 后统一汇总评论、水印、版本差异及状态同步警告。

### 验收证据

- 双工位任务隔离、双仓库门禁放行与未授权仓库拒绝测试结果。
- 阶段、授权、验证、CI 预算和证据敏感内容测试结果。
- 接管水印与状态意图、缺字段跳过、写后回读、外部失败不阻断本地推进，以及 PR Ready 三类事实核对结果。
- 分阶段用例、单项单方式、用户处置、确认失效、并发恢复及评论回读的质量测试；真实测试平台和 Jira 联调验收与本地夹具验证分开记录。
- 双工位隔离、完整基线、四操作恢复、目录重置、日志脱敏保留、源码成果可重建、档案不变、refs保留和顺序复用测试。
- 同名源码目录保护、无构建配方清理、未登记 ignored 成果保全、脚本部分失败或完全不执行时的 Agent 接力、成功退出但残留拒绝、解绑中断后证据复核及跨 epoch 拒绝测试。
