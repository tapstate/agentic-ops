# TapData 核心硬规则

- Jira 是任务目标、计划、团队进度、决策和验收事实源；Git 与 GitHub 分别是代码和审查事实源。
- 所有人可见的 Jira 内容使用中文；字段名、状态名、Issue Key 和协议标识可以保留原文并解释。
- 保护分支不得直接提交或推送；合并、发布、Tag、范围扩大和不可逆操作必须人工确认。
- 外部写入执行 `plan -> apply -> readback`；结果不明确时先回读，不重复副作用。
- 不提交 token、私钥、客户数据、原始敏感响应或本机私有配置。
- Jira Custom Field 只按稳定 field ID 操作；涉及字段元数据、Context、Screen、权限或跨项目语义时进入专题治理。
- Worklog 只记录真实处理耗时和明确工作内容，不包含等待人工、等待外部系统、无人处理暂停和 CI 排队。
