# Tapdata 运行手册索引

本目录保存 Tapdata 项目级运行手册。运行手册提供可复用的分析和操作路径，不替代目标分支代码、CI、项目硬规定或人工决策。

## 使用顺序

1. 先读取 `../profile.yaml` 和 `../standards/development-rules.md`。
2. 根据 Jira 卡片确认目标仓库、目标分支和变更范围。
3. 读取与任务匹配的运行手册。
4. 用目标分支的构建配置校验手册示例。
5. 执行测试并记录命令、结果、未验证范围和人工门禁。

## 手册

- [构建、测试与本地运行](build-test-and-local-run.md)：适用于环境确认、后端和前端构建、模块测试、本地启动及日志定位。
- [tapdata-common-lib 升级](common-lib-upgrade.md)：适用于公共 API 或版本变化后的多仓影响分析、同步和验证。
