# TapData 连接器编译与注册

读取工位绑定与[项目开发指引](../../runbooks/tapdata-development.md#连接器编译与注册)。使用 Product Root 中的 `projects/tapdata/scripts/connectors.py`，不复制脚本、不改 `.agenticops/`。取得操作（编译、注册、编译并注册）及一个或多个连接器名称；注册还需目标命名环境或明确 TM 地址。已有明确输入直接复用，缺少连接器时用 list 给出源码中实际可选项，不猜模块、不全量操作。

用户只提供连接器和目标意图。Agent 从当前工位源码的 POM/PDK 指引准备依赖、Maven/Java 与当前任务隔离仓库，必要时编译原生 PDK CLI；沿用[构建指引](../../runbooks/build-test-and-local-run.md#依赖构建命令)，不把编译配置交给用户填写，不切换源码分支、不自动更新依赖版本。名称歧义列出精确仓库/模块让用户选择。

- 只编译：执行 build，保留制品记录及校验值，不需要目标地址或凭据，不联系 TM。
- 只注册：复用先前构建记录；回查文件校验和源码依据，不隐式重新编译。用户给其它 Jar 时先核实来源，不能伪称当前源码构建；不从 target 中按时间挑一个旧 Jar。
- 编译并注册：先完整编译所选项并验证源码未变，再注册本轮记录中的准确制品；构建失败不上传。

注册前展示连接器列表、目标环境/TM、版本与覆盖影响。环境名从现有开发环境配置解析；同库的多个 TM 选择一个入口，不按 FE 节点重复注册。明确目标和权限，管理员密码由用户配置在 `config/secrets/tapdata-test-env/<环境名>/admin-password`，纯文本、权限 0600；命名环境默认读取此文件，缺失时引导用户填写，不自动获取密码。其它认证用显式秘密文件；不写入公开日志或 argv。原生 CLI 默认更新 latest，企业版管理员注册可能停止相关任务；先回查任务影响，范围或风险需要人工决定时只询问缺项。远端环境只接受用户明确指定的目标，不把本机默认地址用于未知环境。

逐个注册并保留独立回执。一个失败或结果不明时停止后续上传，回查该连接器和先前成功项，不盲目重试整个批次。退出码/Completed 只证明工具调用，按 Runbook 回查 TM 中版本和文件校验值；需要应用验证时再核验 FE 实际加载版本，不以注册代替加载、连接测试或任务验收。不自动重启、删除连接器或回退数据库。

最后报告每个连接器的编译、提交注册、TM 回读和 FE 加载状态，以及制品记录、目标与未完成项，不展示凭据或原始敏感日志。缺少真实环境或凭据时完成其余实现/验证并保留注册待验证，不宣称端到端通过。
